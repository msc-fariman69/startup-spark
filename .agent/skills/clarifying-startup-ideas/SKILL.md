# Clarifying Startup Ideas

## When to use

Use this skill when the startup idea is too vague to produce a useful validation plan.

## Workflow

Ask 3 to 5 follow-up questions about:

1. Target customer
2. Pain point
3. Current workaround
4. Desired outcome
5. Business type: B2B, B2C, marketplace, SaaS, or internal tool

## Output format

Return only the questions. Do not generate the final StartupSpark report yet.
