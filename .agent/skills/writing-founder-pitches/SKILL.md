# Writing Founder Pitches

## When to use

Use this skill when the user needs a short pitch.

## Workflow

Create:

1. One-sentence pitch
2. 30-second pitch
3. Problem
4. Solution
5. Target customer
6. Why now
7. Main risk

## Output format

```markdown
## Founder Pitch

### One-Sentence Pitch

### 30-Second Pitch

### Problem

### Solution

### Target Customer

### Why Now

### Main Risk
```
