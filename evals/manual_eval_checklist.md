# StartupSpark Manual Evaluation Checklist

Use this checklist for each demo run.

## Trigger behavior

- [ ] Clear idea generates the full 10-section report.
- [ ] Vague idea asks follow-up questions.
- [ ] Landing page request focuses on copy.
- [ ] MVP request focuses on first version.
- [ ] Pitch request creates a short pitch.

## Output quality

- [ ] Includes Idea Summary.
- [ ] Includes Target Customer.
- [ ] Includes Pain Point.
- [ ] Includes Value Proposition.
- [ ] Includes MVP Scope.
- [ ] Includes Landing Page Copy.
- [ ] Includes Validation Experiments.
- [ ] Includes Risks.
- [ ] Includes 7-Day Action Plan.
- [ ] Includes Short Pitch.
- [ ] Clear target customer.
- [ ] Practical MVP scope.
- [ ] 3 to 5 validation experiments.
- [ ] Honest risks.
- [ ] No fake statistics.
- [ ] No promise of success.
- [ ] Good Markdown formatting.

## Capstone quality

- [ ] Uses ADK.
- [ ] Has local tools.
- [ ] Has skill files.
- [ ] Has specs.
- [ ] Has eval cases.
- [ ] Has README run instructions.
- [ ] Demo can be run locally.
