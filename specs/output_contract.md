# StartupSpark Output Contract

The agent must return one Markdown document using the exact top-level section order below.

## 1. Idea Summary

Summarize the startup idea in 2-4 sentences. Clarify what the product is, who it is for, and the core outcome.

## 2. Target Customer

Describe the most likely early adopter segment. Include relevant traits, context, and why this segment feels the pain urgently.

## 3. Pain Point

State the painful problem in concrete terms. Mention the current workaround or failure mode when possible.

## 4. Value Proposition

Explain the main promise of the product. Keep it specific and tied to the pain point.

## 5. MVP Scope

List the smallest useful feature set needed to test the core value proposition. Separate must-have features from later features when useful.

## 6. Landing Page Copy

Include:

- Headline
- Subheadline
- 3 benefit bullets
- Call to action

## 7. Validation Experiments

Provide 3-5 experiments that a founder can run quickly. Each experiment should include the goal, method, and success signal.

## 8. Risks

List the biggest risks, including customer demand, willingness to pay, acquisition, feasibility, or differentiation risks.

## 9. 7-Day Action Plan

Provide one concrete action for each of the next 7 days.

## 10. Short Pitch

Write a concise pitch in 1-3 sentences.

## Formatting Rules

- Use Markdown headings.
- Keep the response concise.
- Prefer bullets for scannability.
- Do not include citations or web-research claims.
- Do not include sections outside the contract unless the user asks.
